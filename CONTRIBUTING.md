# Contributing to Tayra-Sakurai/StockpileManNeo

Welcome to [Tayra-Sakurai/StockpileManNeo](https://github.com/Tayra-Sakurai/StockpileManNeo)! We welcome your contribution.

## Contributors's Guide

Please read [Code of Conduct](./CODE_OF_CONDUCT.md) before contributing to this repository.

## How to Contribute

Please be careful of the following notes.

### Before Submitting a New Issue

Please search for similar issues before you submit a new issue. Please ensure no duplicate issues being submitted.

### How to Make a Pull Request

Please follow the following procedures.

1. Please **fork** this repository.
2. Please make a new branch (the name of the branch is free).
3. Please edit in the branch.
4. Please make the pull request.
