# Get Started

Welcome to StockpileMan neo! This page is the setup guide for new users.

## Sign Up

To get started, please sign up for the application from the [Sign Up Page](https://stockpile-man-neo.vercel.app/signup/).

Please register your display name and login information (email address and password).

When you receive an email from <noreply@mail.app.supabase.io>, please follow the instructions written in the email. Then you have completed your sign up.

## First Database Register

Please hover or touch the "&plus;" icon button displayed bottom right corner to display the speed dial to add a new item to the database.
