# 始める

このページでは，登録方法から初期入力までを説明します．

## このページを読んで理解できること

## アカウント登録

このアプリケーションは無料のアカウント登録が利用に必須となっています．ここでは，アカウント登録の方法を解説します．

[こちらの登録ページ](https://stockpile-man-neo.vercel.app/signup)からアカウント表示名・メールアドレス・パスワードを設定し，「新規登録」ボタンをクリックすると登録案内用のメールが <noreply@mail.app.supabase.io> から送信されます．このメールに書かれたリンクをクリックするとアカウントが自動的に登録されます．

サインイン画面に転送された場合は，そこでメールアドレスと先ほど設定したパスワードを入力してサインインしてください．

## 最初の入力作業

初期入力はデータベースの設定上最も重要な作業です．ここでは，その作業を順序良く行っていくための方法を説明します．なお，サポートが必要な場合は<tayra_sakurai@icloud.com>までお問い合わせください．可能な場合はリモートでのサポートを提供します．

### カテゴリの設定・登録

この作業を始める前に，大分類・小分類のイメージを明確にしておくことが重要です．例えば，食品のデータと日用品のデータを同時に管理する場合には「食品」・「日用品」といった大分類が考えられるはずです．

小分類は，食品であれば，「調味料」・「粉類」・「だし材料」といったような，やや大きめの分類でよいでしょう．

これらのイメージが固まったら，早速登録を進めていきましょう．画面右下に表示されている青い「&plus;」をタップまたはマウスでホバーすると，メニューが開いてアイコンが表示されます．ここから，ツリー状のアイコンをクリックすると大分類の新規登録ページが開きます．ここで大分類を登録してください．

同様に小分類（丸と三角と四角のアイコン），名称（しおりの付いた本）を登録してください．これらを登録するときにはその親になるカテゴリの設定を行ってください．

### 保管場所の登録

保管場所を設定していきましょう．これはピンのアイコンから登録できます．

### 品目の登録

iPhoneであればバーコードを読み取った状態で登録することで品目の次回以降の登録を簡単にすることができます．
