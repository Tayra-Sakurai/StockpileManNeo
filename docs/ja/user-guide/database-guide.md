# データベースガイド

データベースの使い方を解説します．

## データベースの階層構造について

このアプリのデータベースの各品目は**二重の**階層構造の最下層にあります．

このアプリでは，カテゴリと保管場所は**独立の**データとして管理されているため，カテゴリと関係なく保管場所を設定できます．一方で，バーコードの自動入力は保管場所の変動を考慮し，意図的に保管場所を保存しないようになっています．これができるのもカテゴリと保管場所が別のデータになっているからです．
