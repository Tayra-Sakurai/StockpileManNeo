This is an application to manage your home's stockpile of daily-need items and food.

## Installation

No download or installation of this application is needed. You can use this application as you just sign up for the application.

## Documentations

### Chat Page

This application's homepage is the chat page to talk with an AI agent powered by Gemini 3.5 Flash-Lite. This agent helps you search for your needs of items with accessing the API functions via tools.

This chatbot is available for only the **free tier** rate limits. For every response, a snackbar tells you the remaining tokens.

### Stockpile Search Page

This application's search page is AI-integrated phrase search page. As you type the search phrase, Gemini-powered search machine searches for your stockpile.

You can see the search result in card style. The card contains the category information and an abstract information of items.

### Stockpile Item List

The list of items is the table style view page of the items registered on the database.

The filter form can be used to filter the items to display.

### Location View Page and Category View Pages

These pages display the locations or categories, and the number of items in the location or under the category.
