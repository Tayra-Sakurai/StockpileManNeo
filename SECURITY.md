# Security Policy

This policy reveals the process of reporting vulnerabilities to the developer and security support policy of this application.

## Security Update Support

Being a Web application optimized for a certain website, security update is only supported for the latest version.

The official website only offers the latest version of this application.

## If You Find Vulnerabilities on This Repository

Please tell us the findings by using the GitHub's Private Reporting function. Please do not report the vulnerabilities on Issues page.
