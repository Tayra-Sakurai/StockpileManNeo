このプログラムは，在庫管理のためのWebアプリケーションです．このアプリケーションの利用者は家庭を想定して開発されました．

## インストール

このソフトウェアはWebアプリなので特にインストール等は不要です．<https://stockpile-man-neo.vercel.app/>にアクセスし，メールアドレスとパスワードを登録すれば誰でも利用できます．

## 基本機能

このアプリは以下のような機能を備えています．

### AIチャットボット

Geminiを用いたチャットボットでデータベースを検索したり，データベースの内容について質問したりできます．現在は制限が厳しい状態ですのですぐに使えなくなる可能性がございますが，悪しからずご了承ください．

### 検索ページ

AI組み込みの検索機能を用いて項目を検索できます．

### 一覧表示

大分類・分類・名称・在庫を一覧表の形式で閲覧できます．
